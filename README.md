# Unlabelled Futures

BUILD AN INTERACTIVE WEBSITE: UNLABELLED
Project Overview

Create a sophisticated, futuristic, fully responsive and interactive web application called UNLABELLED, based in Dubai, UAE.

Tagline: "Your potential has no stereotype."

The application should address the United Nations Sustainable Development Goals:

SDG 4 – Quality Education
SDG 5 – Gender Equality

The central theme is Dubai – IT (Information Technology).

The platform's primary mission is to challenge gender stereotypes in education, expose inequalities, encourage equal educational opportunities and provide students with a safe way to ask questions, express concerns and report unfair treatment.

The website should feel like a premium Dubai-based technology initiative, not a conventional school project or generic dashboard.

It should combine social impact, technology, data journalism, interactive storytelling and elegant futuristic design.

Enable and configure Lovable Cloud (Supabase) for:
- Secure Speak Up reports submission and management (with reference numbers, category, anonymous flag, timestamp, status).
- User authentication and role-based access where relevant.
- Dynamic impact counters (myths challenged, reports submitted, resources explored).
- ECHO AI educational chatbot assistant and support gateway.
